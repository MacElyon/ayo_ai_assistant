# Ayo - Personal AI Assistant

Ayo is a local AI assistant built in Python using Ollama and Google Calendar API.

## Features

- Local LLM inference using Ollama
- Persistent conversation memory with SQLite
- Google Calendar integration
- Calendar event creation
- Calendar event retrieval
- Calendar event deletion
- Tool calling architecture

## Technologies

- Python
- Ollama
- SQLite
- Google Calendar API

## Current Status

Ayo is actively being developed. Future improvements include:
- Voice integration
- More tools
- Improved planning/reasoning
- Better memory systems
